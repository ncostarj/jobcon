## RPA Nodejs CLI

RPA CLI is a tool for run robots for our automation.

## Installation

```bash
npm install -g rpa
```

## Usage

To start using RPA CLI, run:

```bash
rpa -h|--help
```

### Commands

- `rpa ponto`: Executes a robot to push clockhour button.
- `rpa portalrh`: Executes a robot to interact with portalrh site.
- `rpa noticias`: Executes a robot to extract the newest news from g1.com.

For more detailed information on commands, run `rpa --help` and info will be shown.
